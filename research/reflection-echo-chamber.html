When Reflection Becomes an Echo Chamber

A second reasoning pass can correct an answer. It can also repeat the same assumption, reuse the same weak evidence and make the error more persuasive.

The important question is not “did the model think twice?” It is “what new information or independent constraint entered the second pass?”

Reflection is not one mechanism

Self review by the same model, critique by another model, external evidence checking and professional review are different interventions. They should not be treated as equivalent merely because each adds another step.

Healthcare makes correlated failure especially important

A model may receive an incomplete chronology, ambiguous description or misleading source. Repeating reasoning over the same foundation does not repair the missing input.

A DigiDr experiment

Compare single pass, same model self review, evidence assisted revision and governed professional review on matched tasks. Measure corrections, new errors, unsupported certainty, uncertainty preservation and review effort.

Stopping conditions matter

An agent that can always reason again needs a reason to stop. More iterations are not useful when no new eligible information enters the system.
