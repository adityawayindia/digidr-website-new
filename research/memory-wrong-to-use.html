Memory Can Be Correct: and Still Be Wrong to Use

Remembering a fact accurately is only one requirement. The current task may no longer have permission to use it, the information may be stale or the patient may have corrected it.

A memory system should answer two questions: can I recall this, and may I use this now?

Persistence is not continuous model activity

A persistent context responsibility can live in versioned records and explicit update rules without keeping a model session running.

Time needs more than one timestamp

When a fact was true can differ from when the system learned it. Historical truth should not be silently treated as current.

Permission changes eligibility

A correctly remembered patient detail can still be unavailable for a different purpose or after a permission change.

Correction should travel downstream

If a patient corrects a detail, future ContextPacks should use the current record while historical accountability remains distinguishable.
